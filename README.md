## 让 Agent 在聊天里会发各种有趣的表情

我做了 [sticker-cli](https://github.com/9Ashwin/sticker-cli)，一个面向 AI Agent 的本地表情包 CLI。它让 Agent 在聊天中不只是回复文字，还能按场景搜索、挑选和展示各种有趣的表情包。

- 精选或全量素材包按需安装
- 支持 GIF、PNG、WebP 预览
- 导入自己的表情，收藏、分类、排序和整理
- 安装 Skill 后，直接说“发个调皮的表情”就能触发

公共素材在 [sticker-ext](https://github.com/9Ashwin/sticker-ext)。

```bash
curl --proto '=https' --tlsv1.2 -fsSL \
  https://raw.githubusercontent.com/9Ashwin/sticker-cli/main/scripts/install.sh | bash
```
